📝 Syntax & Semantics

CSS Variable Usage

Colors are defined as space-separated RGB values and used with the rgb() function:

/* Define the variable */ :root { --color-primary: 59 130 246; /* Blue RGB values */ } /* Use the variable */ .bg-primary { background-color: rgb(var(--color-primary)); } /* With opacity */ .bg-primary\/20 { background-color: rgb(var(--color-primary) / 0.2); }

🎭 Creating Custom Themes

Step 1: Define Your Theme

Create a new theme by defining CSS variables under a [data-theme="your-theme-name"] selector:

/* Custom Ocean Theme Example */ [data-theme="ocean"] { --color-primary: 6 182 212; /* cyan-500 */ --color-primary-focus: 8 145 178; /* cyan-600 */ --color-primary-content: 255 255 255; /* white */ --color-secondary: 14 165 233; /* sky-500 */ --color-secondary-focus: 2 132 199; /* sky-600 */ --color-secondary-content: 255 255 255; /* white */ --color-accent: 59 130 246; /* blue-500 */ --color-accent-focus: 37 99 235; /* blue-600 */ --color-accent-content: 255 255 255; /* white */ --color-neutral: 8 145 178; /* cyan-600 */ --color-neutral-focus: 14 116 144; /* cyan-700 */ --color-neutral-content: 255 255 255; /* white */ --color-base-100: 236 254 255; /* cyan-50 */ --color-base-200: 207 250 254; /* cyan-100 */ --color-base-300: 165 243 252; /* cyan-200 */ --color-base-content: 22 78 99; /* cyan-900 */ /* Semantic colors */ --color-info: 14 165 233; /* sky-500 */ --color-info-content: 255 255 255; /* white */ --color-success: 34 197 94; /* green-500 */ --color-success-content: 255 255 255; /* white */ --color-warning: 245 158 11; /* amber-500 */ --color-warning-content: 255 255 255; /* white */ --color-error: 239 68 68; /* red-500 */ --color-error-content: 255 255 255; /* white */ }

Step 2: Color Guidelines

Required Variables

  • • --color-primary & --color-primary-focus
  • • --color-secondary & --color-secondary-focus
  • • --color-accent & --color-accent-focus
  • • --color-neutral & --color-neutral-focus
  • • --color-base-100, --color-base-200, --color-base-300
  • • --color-base-content

Best Practices

  • • Use RGB values without rgb()
  • • Ensure good contrast ratios
  • • Test in both light and dark environments
  • • Focus colors should be darker than base colors
  • • Content colors should contrast well with backgrounds

🔄 Adding to Theme Switcher

Step 1: Add to CSS File

Add your theme definition to src/styles/daisy-themes.css:

/* Add this to daisy-themes.css */ [data-theme="your-theme-name"] { --color-primary: 59 130 246; --color-primary-focus: 37 99 235; /* ... rest of your theme variables */ }

Step 2: Update Theme Switcher

Add your theme to the DAISY_THEMES array in src/components/shared/DaisyThemeSwitcher.jsx:

const DAISY_THEMES = [ { name: 'light', label: 'Light', description: 'Clean and bright' }, { name: 'dark', label: 'Dark', description: 'Easy on the eyes' }, // ... existing themes { name: 'your-theme-name', label: 'Your Theme', description: 'Your custom theme' }, ];

Step 3: JavaScript Theme Switching

Programmatically switch themes using JavaScript:

// Switch to your custom theme document.documentElement.setAttribute('data-theme', 'your-theme-name'); // Get current theme const currentTheme = document.documentElement.getAttribute('data-theme'); // Save theme preference localStorage.setItem('theme', 'your-theme-name');
