🏦 Account-Specific Paycheck Calculations Test

This test demonstrates how the budget table now calculates paycheck countdowns based on which account an expense/goal is assigned to.

📋 Test Scenario

Problem: Car payment due on 1st, but assigned to "Bills Account" which gets paid on 30th, while "Main Account" gets paid on 2nd.

Before: System would count ALL paychecks → "1 paycheck left" (incorrect)

After: System filters by account → "0 paychecks left" (correct)

Account 2: Bills Account
ID: 2, Gets paycheck on: 30th of each month

💰 Test Paychecks

Paycheck 1: $2000 to Main Account (ID: 1) on January 2nd
Paycheck 2: $1500 to Bills Account (ID: 2) on December 30th

🚗 Test Expense

Car Payment: $350 due January 1st, assigned to Bills Account (ID: 2)

🧮 Calculation Logic

// Enhanced calculatePaychecksUntilDue function calculatePaychecksUntilDue(dueDate, upcomingPaychecks, accountId) // Step 1: Filter paychecks by account relevantPaychecks = upcomingPaychecks.filter(paycheck => paycheck.accountDistribution.some(dist => dist.accountId === accountId ) ) // Step 2: Count paychecks before due date return relevantPaychecks.filter(paycheck => paycheck.date <= dueDate ).length
